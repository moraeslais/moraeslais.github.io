# Laís Moraes · Portfólio

Portfólio de UX/UI & Product Design. No ar em **https://moraeslais.github.io/**

- Página inicial, 6 estudos de caso e currículo, em **português, inglês e espanhol**
- Tema **claro e escuro**, seguindo a preferência do sistema
- Protótipos navegáveis do Squad, Venzi, EduMentor AI e Fixer AI
- Feito em HTML, CSS e JavaScript, sem framework, com apoio de IA (Claude) no desenvolvimento

## Estrutura

| Caminho | O que é |
|---|---|
| `index.html` | Página inicial |
| `case.html` + `cases/*.js` | Estudos de caso (rota por `#case-...`) |
| `cv.html`, `cv-en.html`, `cv-es.html`, `cv/` | Currículo web e PDFs |
| `squad/`, `venzi/`, `edu/`, `fixer/` | Protótipos navegáveis |
| `img/` | Imagens, capas e vídeos |

## Rodar localmente

```bash
python3 -m http.server 8000
# abra http://localhost:8000
```
